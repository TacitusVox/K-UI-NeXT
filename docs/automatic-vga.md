# Automatic VGA compatibility

Connect the VGA cable before starting K-UI. Launch the game from **Games** on SD, or choose **A / K-UI boot** in **GD Play** for an original native Dreamcast disc. When the loaded program matches a catalog entry, the reader applies the fix in RAM before it starts the game.

## Built-in catalog

The catalog contains **64 boot-program profiles**. Of these, 52 match all 45 entries in the November 24, 2026 ConsoleMods patch table. The remaining 12 cover other regional editions, trials and US Gunbird 2. Some discs in a set share a program. The table identifies the exact releases, including the English translation of Seven Mansions. [Community patch cross-reference](evidence/automatic-vga/expanded/community-index.md)

**The King of Fighters Dream Match 1999** (US v1.004) has a working-video report from a Dreamcast running an earlier build. **The King of Fighters Evolution** (US v1.000) has a separate host-tested profile. The early Japanese editions still need their own fixes. Host tests check the catalog and its executable changes. Most releases still need in-game display tests on a Dreamcast.

## Selecting the right fix

- **Native Games and GD Play** check the release and program length. Depending on the profile, the reader verifies a fingerprint of the loaded program or computes the SHA-256 it would have after the edits. It checks the affected bytes at handoff before applying the fix.
- **Games on SD** can also use a prepared VGA GDI when a full-disc correction changes movies, audio or files loaded later. Launch the ordinary menu entry to keep its settings and save identity. K-UI checks the cable, the release, the disc number and whether it can read the prepared image. [PC preparation and per-release instructions](vga-prescriptions.md)
- **Discs missing only the VGA header flag** can already reach the game through K-UI’s bootstrap. The game still selects the video mode during play. [Boot-path evidence](evidence/automatic-vga/boot-admission.md) · [Regional hardware surveys](evidence/automatic-vga/regional-surveys.csv)
- **GD Play → X / Stock boot** hands the disc to the console BIOS. A prepared image requires Games on SD. Windows CE games use their own display drivers.

**US Gunbird 2** v1.000 has a host-tested fix for stage slowdown, the Gallery and the loading graphic. The reported K-UI launch stopped while reading the executable, before the VGA fix could run. An in-game K-UI result is still pending. On DCHDMI, DCDigital or RetroGEM, the author specifies **Force VGA** in the device menu. [Author’s patch and test notes](https://github.com/DerekPascarella/Gunbird2-VGASlowdownFixDreamcast)

**PAL Skies of Arcadia** uses the built-in executable fix on both discs. Riggles’ separate Perfect 60Hz release also changes cutscene assets. Install its matched companion for each disc to use that version. [Publisher instructions](vga-prescriptions.md)
